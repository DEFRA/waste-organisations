# Stub generation

The tests in this location generate stubs to track the response shape of the service.

If things change and the stubs need to be updated, run these tests and copy the contents of the Generated folder (JSON files) into the Scenarios folder of the stub service https://github.com/DEFRA/waste-organisations-stub

More scenarios can be added as needed.

Organisation IDs used come from either what is used for load tests or what is used in the https://github.com/DEFRA/epr-local-environment configuration.
