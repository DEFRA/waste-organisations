Before writing or changing a spec, read the "Specs" section of `AGENTS.md`. A new spec comes from the `spec-clarify` skill; a spec whose work exceeds the PR size guide stays one spec and is sliced in its Work breakdown, one pull request per slice. A delivered spec (its story merged, for example 0001 to 0004) is never edited: record the change in the new spec and name the spec it supersedes.
